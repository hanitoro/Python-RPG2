АКТИВНОЕ ЗАДАНИЕ

Где писать код?
Только в папке tasks. Открой нужный .py в VS Code / PyCharm / IDLE, внеси правки и нажми Ctrl+S.
Потом открой CHECK_Н.bat (где Н — номер комнаты). Для игры нужно загрузить исправленный файл и протокол checks/stage_Н.json.
Как сдавать?
В конце скачай журнал, помести его в общую папку квеста и запусти MAKE_SUBMISSION.bat. Отправь полученный ZIP преподавателю электронно.
Работает полностью офлайн · Требуется Python 3 · Итоговая оценка определяется по исходникам и тестам, а не по кликам.

Начать расследование заново?

Переписка начнётся с первого сообщения. Найденные улики, сюжетные выборы, пройденные комнаты и концовка будут сброшены.

Важно: таймер НЕ сбросится, отсчёт продолжится от первого нажатия «Начать расследование». Твои файлы tasks/*.py и результаты проверок на компьютере НЕ удаляются. Если хочешь сохранить прежний прогресс, сначала скачай журнал.
