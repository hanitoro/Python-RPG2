PYTHON RPG — СПЕЦИАЛЬНАЯ МИССИЯ «ПРИЗРАК В КОДЕ»
=================================================
Одиночный автономный квест • 60 минут • Python 3 • без интернета

С ЧЕГО НАЧАТЬ
1. Распакуй ВЕСЬ архив в отдельную папку на рабочем столе.
   Не открывай HTML и .py прямо из ZIP — иначе проверочные файлы
   могут сохраняться не в том месте.
2. Рекомендуемый запуск в Windows: дважды щёлкни START_GAME.bat.
   Откроется браузер с игровым чатом. Не закрывай появившееся
   окно сервера до конца квеста. Это локальный адрес, без интернета.
   Если .bat не работает, можно открыть START_HERE.html напрямую.
   Сначала откроется стартовый экран. Введи имя персонажа
   и нажми «НАЧАТЬ РАССЛЕДОВАНИЕ», чтобы одновременно запустить
   СЮЖЕТ и ТАЙМЕР НА 60 МИНУТ. Пока изучаешь стартовый экран,
   время не идёт. При повторном открытии страницы таймер
   продолжает первый отсчёт.
   Через START_GAME.bat сохранение прогресса в браузере надёжнее.
3. Читай сообщения персонажей и выбирай ответы. Если случайно
   прокликал важные сообщения, нажми «↻ Начать заново» вверху игры,
   затем подтверди сброс. Квест вернётся к стартовому экрану.
   Время первого запуска расследования НЕ сбросится. Исправленные Python-файлы
   останутся на компьютере, но загрузить их проверки придётся снова.
4. Когда появится комната 1, открой tasks/terminal.py в редакторе.
   Редактируй .py ТОЛЬКО в папке tasks/ и СОХРАНЯЙ через Ctrl+S.
5. Запусти CHECK_1.bat (дважды щёлкни, Windows) или команду:
       python CHECK.py 1
   Если тесты прошли, появится файл checks/stage_1.json.
6. Вернись в START_HERE.html и выбери ДВА файла:
       tasks/terminal.py
       checks/stage_1.json
   Нажми «ПОДТВЕРДИТЬ РЕЗУЛЬТАТ В ИГРЕ».
7. Продолжай диалоги. В комнате 2 меняй tasks/trader.py,
   в комнате 3 — tasks/vault.py, в комнате 4 — tasks/guardian.py
   И tasks/student_tests.py (два assert).
8. В конце скачай журнал прохождения, перемести journal_aurion.txt
   из «Загрузок» в ЭТУ ЖЕ ПАПКУ, где лежит START_HERE.html.
9. Дважды щёлкни MAKE_SUBMISSION.bat и отправь полученный
   файл SUBMISSION_AURION.zip преподавателю электронно.

ПОМОЩЬ БЕЗ ПОДХОДА К ПРЕПОДАВАТЕЛЮ
- В игре слева есть 3 подсказки к каждой комнате.
- В начале каждого .py написан контракт функций.
- В окне CHECK_N.bat написано, какая конкретно проверка не прошла.
- Если всё не успел — скачай журнал, сдай текущую версию и честно укажи это.

ВАЖНО
- Для запуска .py и CHECK.py нужен установленный Python 3.
- Код проверяется локально. Источники и проверки не отправляются на сервер.
- Не меняй CHECK.py, JSON-протоколы или HTML — это не решение задания.
- Изменил .py после успешной проверки? Нужно запустить проверку повторно.
- Таймер служит ориентиром времени, а не системой блокировки.
- Полностью защитить офлайн HTML и локальные часы от изменения нельзя.
  Поэтому оценка определяется по исходникам и прохождению тестов.
- Для новой честной попытки преподаватель может выдать свежую копию архива.

ПРОГРЕСС И ТАЙМЕР
- Первое нажатие «Начать расследование» фиксирует время
  в хранилище данного браузера. До нажатия кнопки время не идёт.
- Повторный запуск через START_GAME.bat в том же браузере сохраняет
  таймер, найденные улики и полученные результаты.
- Не очищай данные браузера и не меняй браузер посреди игры.
- Таймер не останавливает незавершённую работу автоматически.
- «Начать заново» сбрасывает сообщения, улики, сюжетный прогресс
  и отметки прохождения в браузере, но НЕ обнуляет 60-минутный таймер.
- Файлы в папке tasks/ при перезапуске НЕ удаляются и НЕ возвращаются
  к исходному виду. Для чистой версии кода распакуй архив в новую папку.
